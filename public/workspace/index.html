Common questions

Can I purchase or generate an API key now?

Not yet. API WILD supports discovery, cost planning and configuration. Billing and model provisioning are not connected.

Can I bring my own provider keys?

BYOK is planned. Do not enter API keys in this preview. Secure server-side key storage and provider access must be connected first.

What happens if a provider is unavailable?

Production routing needs explicit fallback policies, budgets and failure handling. No automatic fallback or uptime guarantee is active in this preview.

Can you build a tailored agent for my business?

Use Custom solutions to specify your workflow, integrations and autonomy. Download the brief for scoping; the form does not submit an order.
